ШРИФТЫ — положите сюда 3 файла с такими именами:

  oswald-600.woff2   (Oswald, начертание SemiBold 600)
  inter-400.woff2    (Inter, Regular 400)
  inter-600.woff2    (Inter, SemiBold 600)

Где взять (бесплатно, лицензия OFL):
  1. Откройте https://gwfh.mranftl.com/fonts  (google-webfonts-helper)
  2. Найдите Oswald -> в Charsets отметьте: latin, latin-ext, cyrillic -> в Styles отметьте 600
     -> в блоке "Copy CSS" выберите "Modern Browsers" -> Download files (zip).
  3. То же для Inter: отметьте 400 и 600 (те же Charsets).
  4. Из zip возьмите файлы .woff2, переименуйте как выше и положите в эту папку.

Пока файлов нет, сайт показывает запасные шрифты (выглядит чуть иначе, но работает).
